# soumatsu-design.github.io

宗松（黃琮崧）作品集《黴　かび》的網站。

- https://soumatsu-design.github.io/ ：網站 1「夜から頁へ」
- https://soumatsu-design.github.io/yoru/ ：網站 2「夜の培地」

網站的檔案打包在 `kabi_site.zip.part00`–`part07`（約 68 MB；分成小檔是因為網頁上傳每個檔要在 25 MB 以內）。
之後的小修改放在 `kabi_patch_01.zip`、`kabi_patch_02.zip`……（只放改過的檔）。
推上 main 之後，`.github/workflows/deploy.yml` 會把它組回去、照編號蓋上修改、核對每個檔的 md5，再發布到 GitHub Pages。
